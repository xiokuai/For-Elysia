致爱（ZhiAi）是一门完全以 **中文** 为核心语法的自举编程语言。从关键字、内置函数到控制流，全部采用贴近自然中文习惯的表达方式。它旨在让中文母语者能够以最直观、最优雅的方式书写代码。

## ✨ 核心特性

- **完全中文化**：彻底摆脱英文关键字，使用 `让`、`如果`、`函数` 等直观的中文语法。
- **混合执行架构**：支持标准解释、**极速 JIT (运行时转译)** 以及 **AOT (原生二进制编译)** 三种模式。
- **自举编译器**：致爱的核心编译器 `main.za` 完全由致爱语言自身编写。
- **现代化特性**：支持闭包、高阶函数、匿名函数、**面向对象 (类)** 及完整的数据类型。
- **模块化与工程化**：内置 `导入()` 机制，支持跨文件模块调用与作用域隔离。
- **完美的 IDE 支持**：配套 VS Code 官方插件，提供语法高亮、代码折叠、内联提示与代码片段。

## 🚀 运行与编译

致爱提供了一套强大的命令行工具链：

### 1. 解释执行 (快速调试)
```bash
zhiai run 文件.za       # 传统解释模式
zhiai run 文件.za --jit # 开启 JIT 加速引擎 (提升 20倍+ 性能)
```

### 2. AOT 静态编译 (极致性能)
致爱可以将代码直接编译为不需要任何依赖的 **原生二进制 EXE**：
```bash
# 将源码编译为经过 C 语言级优化的原生程序
zhiai compile 你的代码.za --aot
```

### 3. 交互模式 (REPL)
```bash
zhiai                   # 直接进入中文编程交互世界
```

## 📖 核心语法速览

### 变量与常量
```zhiai
让 名字 = "小明"
常量 圆周率 = 3.14159
```

### 面向对象 (类)
```zhiai
类 猫
  函数 构造(名字)
    这.名 = 名字
  结束
  
  函数 叫()
    输出(这.名 + "喵喵叫~")
  结束
结束

让 我的猫 = 新 猫("咪咪")
我的猫.叫()
```

### 循环与控制
```zhiai
循环 i 从 1 到 1000000
  如果 i % 10000 == 0 则
    输出("已处理: " + 转换文字(i))
  结束
结束
```
