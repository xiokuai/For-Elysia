致爱（ZhiAi）是一门完全以 **中文** 为核心语法的自举编程语言。从关键字、内置函数到控制流，全部采用贴近自然中文习惯的表达方式。它旨在让中文母语者能够以最直观、最优雅的方式书写代码。

## ✨ 核心特性

- **完全中文化**：彻底摆脱英文关键字，使用 `让`、`如果`、`函数` 等直观的中文语法。
- **现代化特性**：支持闭包、高阶函数、匿名函数、对象（字典）及完整的数据类型。
- **模块化与工程化**：内置 `导入()` 机制，支持跨文件模块调用与作用域隔离。
- **多目标编译**：不仅可以解释执行，更能编译出独立运行的 Windows `.exe` 程序或 `.dll`（`.zab`）动态模块库！
- **自举编译器**：致爱的核心编译器 `main.za` 完全由致爱语言自身编写。
- **完美的 IDE 支持**：配套完整的 VS Code 语法高亮扩展，编程体验行云流水。

## 🚀 快速开始

### 安装与配置

如果您下载了最新的 Release 版本，可以直接双击 `zhiai.exe` 运行，或者在命令行中进行操作：

```bash
zhiai                    # 启动交互式 REPL
zhiai 文件.za            # 编译并运行源码文件
zhiai run 文件.za        # 解释执行（快速调试）
zhiai install            # 在 Windows 注册 .za / .zab 文件关联
```

### 独立打包为 EXE 应用程序

致爱支持将你的代码瞬间打包为脱离任何环境、可以在任何 Windows 电脑上运行的独立执行文件：

```bash
# 将你的源码一键编译为带有原生图标的 Windows 可执行文件！
zhiai compile 你的代码.za --exe
```

### 模块化与类库 (DLL 机制)

你可以将代码编译为共享类库，供其他程序调用：

```bash
# 编译库文件（例如 库.za）
zhiai compile 库.za --dll
```

在另一个文件中导入使用：
```zhiai
导入("库")
库.某方法()
```

## ✨ v1.0.1 性能飞跃

在此版本中，我们对致爱语言的工具链进行了全面的性能重构：

- **局部变量列表化**：虚拟机内部使用索引访问局部变量，显著降低查询开销。
- **尾调用消除 (TCO)**：完美支持递归调用复用栈帧，不再担心 `递归深度` 导致的栈溢出。
- **批处理内置函数**：为数组/字符串操作（筛选、映射、排序等）提供底层 C 级加速指令。
- **Cython 极速模式**：可选的 Cython 核心实现，带来 5-10 倍的指令调度速度提升。

### 🚀 运行极速模式

如果您下载的是 `zhiai_fast.exe` 或已安装 Cython 环境，可以使用 `--fast` 参数：

```bash
zhiai --fast 你的代码.za
```

## 📖 核心语法速览

### 第一个致爱程序

```zhiai
输出("你好，Elysia！")
```

### 变量与数据类型

```zhiai
让 名字 = "小明"
让 年龄 = 18
让 是学生 = 真
让 无值 = 空

常量 圆周率 = 3.14159
```
支持 `整数`、`浮点数`、`文字` (字符串)、`布尔`、`空`、`数组` 和 `对象`。

### 控制流

```zhiai
让 分数 = 85

如果 分数 >= 90 则
  输出("优秀")
否则如果 分数 >= 60 则
  输出("及格")
否则
  输出("不及格")
结束
```

### 循环

支持条件循环、数值循环和遍历循环：

```zhiai
// 遍历数组
让 水果 = ["苹果", "香蕉", "橙子"]
对于 每个 水果名 在 水果 中
  输出(水果名)
结束

// 指定步长循环
循环 i 从 1 到 10 步长 2
  输出(i)
结束
```

### 函数与闭包

致爱完美支持函数式编程、高阶函数和闭包：

```zhiai
函数 计数器(初始值)
  让 当前 = 初始值
  函数 增加()
    当前 += 1
    返回 当前
  结束
  返回 增加
结束

让 计 = 计数器(0)
输出(计())    // 1
输出(计())    // 2
```

## 📚 内置函数与方法速查

### 全局内置函数
| 函数 | 说明 | 示例 |
|------|------|------|
| `输出(...)` | 打印到控制台 | `输出("你好")` |
| `输入(提示)` | 读取用户输入 | `让 名 = 输入("名字：")` |
| `类型(值)` | 返回类型名称 | `类型(42)` → `"整数"` |
| `转换数字(值)` | 转换为数字 | `转换数字("42")` → `42` |
| `转换文字(值)` | 转换为字符串 | `转换文字(真)` → `"真"` |
| `长度(值)` | 获取长度 | `长度([1, 2, 3])` → `3` |
| `随机数(小, 大)` | 随机整数 | `随机数(1, 100)` |
| `导入(模块名)` | 加载外部模块 | `导入("test_module")` |

### 数组与对象方法
| 方法 | 说明 | 示例 |
|------|------|------|
| `.添加(元素)` | 数组追加 | `[1].添加(2)` → `[1, 2]` |
| `.筛选(函数)` | 过滤元素 | `[1,2,3].筛选(函数(x) 返回 x>1 结束)` |
| `.包含(元素)` | 是否包含 | `[1,2].包含(2)` → `真` |
| `对象键(对象)` | 获取所有键 | `对象键({"a":1})` → `["a"]` |
| `对象合并(A, B)` | 合并对象字典 | `对象合并(配置, 新配置)` |

### 字符串方法
| 方法 | 说明 | 示例 |
|------|------|------|
| `.分割(分隔符)` | 按字符拆分 | `"a,b".分割(",")` → `["a", "b"]` |
| `.替换(旧, 新)` | 替换子串 | `"hi".替换("i", "a")` → `"ha"` |
| `.截取(始, 终)` | 截取子串 | `"hello".截取(1, 4)` → `"ell"` |
