# 致爱编程语言

致爱（ZhiAi）是一门以中文为语法的编程语言，所有关键字、内置函数和方法均为中文，适合中文母语者学习编程。

## 快速开始

### 安装

双击 `zhiai.exe` 运行，或在命令行中使用：

```bash
zhiai                    # 启动交互式 REPL
zhiai 文件.za            # 编译并运行源码文件
zhiai run 文件.za        # 解释执行
zhiai compile 文件.za    # 编译为字节码
zhiai exec 文件.zab      # 运行字节码文件
zhiai -e '输出("你好")'  # 执行单行代码
zhiai install            # 注册 .za/.zab 文件关联
```

### Hello World

```
输出("你好，世界！")
```

保存为 `hello.za`，运行：

```bash
zhiai hello.za
```

## 基本语法

### 注释

```
// 单行注释

/*

### 变量

```
让 名字 = "小明"
让 年龄 = 18
让 是学生 = 真
让 无值 = 空

常量 圆周率 = 3.14159
```

变量使用 `让` 声明，`常量` 声明不可变的值。赋值不需要关键字：

```
让 x = 10
x = 20         // 重新赋值
x += 5         // 复合赋值：x = x + 5
x -= 3         // x = x - 3
x *= 2         // x = x * 2
x /= 4         // x = x / 4
```

## 控制流

### 条件判断

```
让 分数 = 85

如果 分数 >= 90 则
  输出("优秀")
否则如果 分数 >= 80 则
  输出("良好")
否则如果 分数 >= 60 则
  输出("及格")
否则
  输出("不及格")
结束
```

### 当循环

```
让 计数 = 0
当 计数 < 5 时
  输出("第 " + 转换文字(计数 + 1) + " 次")
  计数 += 1
结束
```

### 数值循环

```
// 从 1 循环到 10
循环 i 从 1 到 10
  输出(i)
结束

// 带步长
循环 i 从 0 到 20 步长 2
  输出(i)    // 0, 2, 4, ..., 20
结束

// 倒序
循环 i 从 10 到 1 步长 -1
  输出(i)    // 10, 9, 8, ..., 1
结束
```

### 遍历循环

```
// 遍历数组
让 水果 = ["苹果", "香蕉", "橙子"]
对于 每个 水果名 在 水果 中
  输出(水果名)
结束

// 遍历字符串
对于 每个 字符 在 "你好" 中
  输出(字符)
结束

// 遍历对象（遍历键名）
让 人 = {"名字": "小明", "年龄": 18}
对于 每个 键 在 人 中
  输出(键 + ": " + 转换文字(人[键]))
结束
```

### 循环控制

```
// 中断（跳出循环）
循环 i 从 1 到 100
  如果 i == 5 则
    中断
  结束
  输出(i)
结束

// 继续（跳过本次循环）
循环 i 从 1 到 10
  如果 i % 2 == 0 则
    继续
  结束
  输出(i)    // 只输出奇数
结束
```

中断        // 跳出循环
继续        // 跳过本次循环
返回 值     // 从函数返回
```

## 编译与执行

致爱有两种运行模式：

- **解释模式**：直接执行 `.za` 源码文件
- **编译模式**：先编译为 `.zab` 字节码，再由虚拟机执行

```bash
# 解释执行
zhiai run program.za

# 编译为字节码
zhiai compile program.za -o program.zab

# 执行字节码
zhiai exec program.zab

# 编译并执行（一步完成）
zhiai program.za
```

字节码文件 `.zab` 是 JSON 格式，包含常量池、指令流和全局变量。
