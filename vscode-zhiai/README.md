# 致爱 (Zhiai) VSCode 插件 v1.5.0 🌸

这是为 **致爱 (Zhiai)** 编程语言打造的专业级 IDE 支持插件。

## ✨ 核心特性

### 1. 现代化开发体验 (v1.5.0 新增)
- **代码折叠 (Code Folding)**：支持折叠 `函数`、`类`、`如果`、`循环`、`尝试` 等逻辑块，让大文件浏览更清爽。
- **内联提示 (Inlay Hints)**：在函数调用处自动显示参数名提示（如 `对话框` 的标题参数），让代码意图一目了然。
- **增强标准库支持**：新增对 `时间`、`格式化时间`、`解析JSON`、`生成JSON` 等内置函数的高亮与补全。

### 2. 高级 IDE 增强
- **大纲视图 (Outline)**：侧边栏展示函数与类的层级，支持快速跳转。
- **参数提示 (Signature Help)**：输入函数时实时弹出参数文档。
- **悬停提示 (Hover)**：鼠标指向关键字或函数显示中文文档。
- **重命名重构 (Rename)**：**F2** 全文件重命名。
- **实时诊断 (Diagnostics)**：保存即触发语法检查。

### 3. 工具链集成
- **一键运行/打包**：右上角图形化按钮支持。
- **自动化格式化**：**Alt + Shift + F**。
