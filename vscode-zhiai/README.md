# 致爱 (Zhiai) VSCode 插件 v1.6.0 🌸

这是为 **致爱 (Zhiai)** 编程语言打造的专业级 IDE 旗舰扩展。

## ✨ v1.6.0 旗舰版新增核心特性

### 1. 🎛️ 真正的可视化调试体验 (Debugger / DAP Engine)
- **断点管理**：支持在代码行号旁直接点击添加、启用或删除红点断点。
- **单步调试**：支持「单步跳过 (Step Over)」、「单步进入 (Step Into)」和「继续执行 (Continue)」。
- **变量查看**：在左侧调试栏 `Frame.locals` 中实时展示当前作用域所有中英文局部变量的真实数值。
- **虚拟机栈监控**：在 `VM.stack` 中实时监控虚拟机的压栈与数据出栈，让字节码执行过程清晰可见。

### 2. 🚨 增强型实时错误诊断与点击修复 (LSP 增强)
- **实时波浪线提示**：采用 `onDidChangeTextDocument` 事件驱动及 **500ms 智能输入防抖**，无需保存文件，打字期间即有毫秒级错误波浪线提醒。
- **点击自动修复 (Quick Fix)**：智能识别 `如果说`、`否则说`、`否则如果说` 等口语拼写语病，支持**一键点击黄色灯泡快速重写**！

### 3. 🧠 作用域感知与 Shape 成员补全 (Semantic IntelliSense)
- **局部作用域提示**：智能识别当前函数上下文，优先补全当前函数的形参及内部声明的局部变量。
- **成员属性推断**：输入 `对象.` 或 `实例.` 后，感应点操作，自动提示 Shapes 系统及原型链的通用操作方法。

### 4. 📦 可视化 ZAP 包管理器 (ZAP Sidebar GUI)
- **侧边栏开发中心**：新增「致爱开发中心」爱心活动栏，内置精美的玻璃态卡片布局模块管理中心。
- **一键后台部署**：支持一键搜索及下载官方扩展（如图形库、工具类），且能智能判定已内置的库（如网络、科学计算），给予温馨的开发者建议提示。

### 5. 🧼 词法 Token 驱动的保存自动格式化
- **高精度格式化**：升级至词法 Token 流驱动，完美忽视字符串字面量和注释中的关键字干扰。
- **保存自动排版**：无缝挂载为 Formatting Provider，享受编写代码随手保存即完美对齐的开发快乐。
