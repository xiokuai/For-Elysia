# 致爱 SSA 架构与 Phi 函数实现指南

## 1. 什么是 SSA (Static Single Assignment)
SSA（静态单赋值）是一种中间表示 (IR) 属性，要求每个变量在代码中仅被赋值一次。
这种形式极大地简化了数据流分析，是现代编译器（如 LLVM, GCC, V8）进行高级优化（死代码消除、常量传播、寄存器分配）的基石。

## 2. 为什么需要 Phi (Φ) 函数
在处理带有分支的代码（如 `如果...否则` 或 `循环`）时，不同分支可能会给同一个变量赋不同的值。
当控制流在分支后汇合时，编译器无法静态确定该变量具体来自哪个分支。

**示例代码：**
```zhiai
让 a = 1
如果 条件 则
    a = 2
否则
    a = 3
结束
输出(a) // 这里 a 是多少？
```

**引入 Phi 函数：**
为了保持单赋值特性，我们在控制流汇合点（Basic Block 的起始处）插入 Phi 函数：
```text
B1:
  a_1 = 1
  JMP_IF_NOT 条件 B3
B2: (Then)
  a_2 = 2
  JMP B4
B3: (Else)
  a_3 = 3
  JMP B4
B4: (Merge)
  a_4 = Φ(a_2, a_3)
  PRINT a_4
```

## 3. 致爱的实现架构
致爱语言在 `v1.0.10` 中正式引入了完整的 SSA 构建引擎。核心实现在 `zhiai/ssa.py` 中。

### 构建步骤：
1. **控制流图 (CFG)**：将线性字节码切分为基本块 (Basic Blocks)，并建立有向连接图 (`zhiai/cfg.py`)。
2. **支配树 (Dominator Tree)**：通过不动点迭代算法计算所有块的支配关系，进而得出直接支配集 (Immediate Dominator)。
3. **支配边界 (Dominance Frontier)**：确定哪些块是其他块的“支配管辖边缘”，这是插入 Phi 函数的确切位置。
4. **Phi 节点放置 (Phi Node Placement)**：遍历变量的定义块，在它们的支配边界中迭代插入 Phi 节点。

## 4. 意义与未来
通过 SSA 架构的引入，致爱语言为后续开发 AOT 本地机器码编译器（将 `.za` 直接编译为不依赖 Python 的可执行文件）铺平了道路，标志着该语言从实验性脚本跃升至工业级静态分析系统。
